# berlindaanaman.com

Static portfolio site. Plain HTML and CSS, no build step, no cookies.

## Deploy or update on Vercel

1. Upload everything in this folder to the GitHub repository connected to Vercel (replace the old files).
2. Vercel redeploys automatically. Framework preset: Other. Build command and output directory: leave empty.
3. Web Analytics: Project → Analytics → Enable (cookieless).
